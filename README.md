# TaskFlow ⚡ - MERN Stack Task Manager

TaskFlow is a responsive, feature-rich Task Management application. It is structured into two main components:

1.  **[Backend Server](./backend)**: Node.js, Express, and MongoDB API handling JWT Authentication and Tasks database queries.
2.  **[Frontend Client](./frontend)**: React.js and Vite dashboard client designed using **pure React inline styles** with dynamic light/dark theme toggle support.

---

## 🚀 Quick Setup Instructions

### Prerequisites
Make sure you have Node.js and MongoDB installed and active on your system.

### Running Backend (Port 5000)
1.  Navigate to backend directory: `cd backend`
2.  Install packages: `npm install`
3.  Launch server: `npm run dev`

### Running Frontend (Port 5173)
1.  Navigate to frontend directory: `cd frontend`
2.  Install packages: `npm install`
3.  Launch client: `npm run dev`
